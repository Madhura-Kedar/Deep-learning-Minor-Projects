# 🧠 Deep Learning Minor Project

This repository contains a collection of deep learning projects implemented as part of my **Deep Learning Minor Project**. Each project focuses on a different neural network architecture and its practical application, covering regression, classification, computer vision, and sequence modeling.

## 📂 Projects

### 1. Artificial Neural Network (ANN) — Regression
- **Objective:** Apply an Artificial Neural Network to solve a regression problem.
- **Focus Areas:** Data preprocessing, neural network architecture, model training, and regression evaluation.
- **Task:** Predict continuous numerical values.

### 2. Artificial Neural Network (ANN) — Classification
- **Objective:** Build an ANN model to classify data into different categories.
- **Focus Areas:** Feature preprocessing, model training, classification, and performance evaluation.
- **Task:** Predict discrete class labels.

### 3. Convolutional Neural Network (CNN) — CIFAR-10
- **Objective:** Build a CNN for image classification using the CIFAR-10 dataset.
- **Focus Areas:** Convolutional layers, pooling, feature extraction, and image classification.
- **Task:** Classify images into one of the 10 CIFAR-10 classes.

## 🚀 Getting Started

Make sure you have Pytorch installed in your system.

### Run the Projects

1. Clone this repository:

   ```bash
   git clone <https://github.com/Madhura-Kedar/Deep-learning-Minor-Projects>
   ```

2. Navigate to the project directory:

   ```bash
   cd Deep-Learning-Minor-Project
   ```

3. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open the notebook for the project you want to explore and run the cells.

Alternatively, you can open the notebooks in Google Colab.
